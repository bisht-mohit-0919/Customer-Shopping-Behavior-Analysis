# Customer-Shopping-Behavior-Analysis
Analyzed 3,900 customer transactions using Python, Mysql, and Power BI to uncover spending patterns, customer segments, product preferences, and subscription behavior. Performed data cleaning, feature engineering, SQL analysis, and built an interactive dashboard to generate actionable business insights and recommendations.

This project analyzes 3,900 customer transactions to understand shopping behavior and business performance. Python was used for data cleaning, missing-value handling, exploration, and feature engineering. Mysql was used to answer important business questions such as revenue by gender, top-rated products, customer segments, discount usage, and subscription behavior. Finally, Power BI was used to create an interactive dashboard with KPIs, filters, and visualizations. The analysis helped identify customer spending patterns, product preferences, and subscription trends. Based on these insights, business recommendations were provided to improve customer loyalty, increase subscriptions, optimize discounts, and support better marketing decisions.
